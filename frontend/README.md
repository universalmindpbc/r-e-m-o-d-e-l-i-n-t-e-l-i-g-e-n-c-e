# Re-Model Intelligence portal frontend

Start with the [main project README](../README.md) for the complete portal, API backend, academic context and licensing.

This directory preserves the local `rmu-site` application layout: `app/`, `server/`, `worker/`, `public/`, `docs/`, `tests/` and `scripts/`. The backend implementation is at the repository root; `backend/` contains additional operator tools and links to that canonical implementation.

Use the Node.js and package-manager versions recorded in `package.json`. Install dependencies and build from this directory after obtaining source-use permission. The existing deployment command is `npm run deploy:staging`, only within an authorised staging update. The permanent proofing URL is https://rmu.universalmind.tv. Production publication requires separate explicit approval.

See [verification](../docs/VERIFICATION.md), [architecture](../docs/ARCHITECTURE.md) and [Academic Context and Doctoral Foundations](../docs/PHD_REVIEW.md).
