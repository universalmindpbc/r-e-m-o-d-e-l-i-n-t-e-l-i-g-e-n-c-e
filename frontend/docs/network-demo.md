## Workflow
Run network_audit through the existing backend environment loader to audit the retained sample. network_operator profiles enriches stored IDs; screen sends the public biographies and campaign posts to the dedicated OpenAI API under the user's explicit data-transfer approval. network_prompt.md is the reusable instruction. Screening is followed by public-source verification and editorial selection. No quota requires invented creator credentials or numeric alignment scores.

The public snapshot contains concise summaries, source links, limitations and dated metrics. Raw corpus, API receipts and credentials remain under ignored backend/private/network-demo. Do not publish raw posts or contact details. Expiry is enforced by the public API; refresh or remove the snapshot before its deadline. This prototype has no unattended scheduler or public paid generation endpoint.
