# Local research and operator tools

These additional tools accompany the portal source. The canonical API implementation is [`../../rmu_backend/`](../../rmu_backend/), with migrations and backend tests at the repository root. Local relative links reuse that implementation.

Operator tools may read private evidence, contact paid providers or write local snapshots. They are source-review material until the relevant permissions, credentials, datasets and operational approvals are present. Private directories and environment files are excluded from Git.
